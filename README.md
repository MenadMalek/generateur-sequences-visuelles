# Générateur de séquences visuelles

Outil web permettant de décomposer une activité en étapes simples et visuelles afin de soutenir la compréhension et l’autonomie de l’enfant.

## Fonctions principales

- création de séquences étape par étape ;
- modèles prêts à l’emploi : douche, habillage, brossage des dents, préparation à l’école, coucher, rangement, repas, sortie, etc. ;
- modèles déjà illustrés ;
- possibilité de remplacer les illustrations par des pictogrammes **ARASAAC**, des symboles **Mulberry Symbols** ou des photos personnelles ;
- numérotation des étapes activable ou désactivable ;
- affichage ou masquage du texte ;
- cases à cocher ;
- ajout d’une case finale **« Terminé »** ;
- réorganisation des étapes par glisser-déposer ou avec les flèches ;
- trois formats d’impression : fiche verticale, bande horizontale ou cartes à découper ;
- enregistrement local de plusieurs séquences ;
- duplication ;
- export/import JSON ;
- impression ou enregistrement en PDF.

## Principe

Le niveau de détail doit être adapté aux besoins de l’enfant. Une séquence trop détaillée peut devenir aussi difficile à traiter que l’activité elle-même.

Un pictogramme n’est pas automatiquement plus accessible qu’une photo ou qu’un mot écrit : le support doit être choisi en fonction de ce que l’enfant comprend réellement.

## Confidentialité

Les séquences enregistrées sont conservées localement dans le navigateur. Elles ne sont pas envoyées vers GitHub.

Pour un usage professionnel autorisé, la conservation et la transmission des données doivent respecter les règles de confidentialité et de sécurité de l’établissement ou du service.

## Ressources visuelles

L’outil permet de rechercher des pictogrammes dans :
- **ARASAAC**
- **Mulberry Symbols**

Les modèles prêts à l’emploi contiennent également des illustrations intégrées qui peuvent être remplacées librement par l’utilisateur.

## Mise en ligne avec GitHub Pages

Dans le dépôt GitHub :

1. Ouvrir **Settings → Pages**.
2. Choisir **Deploy from a branch**.
3. Sélectionner **main** puis **/(root)**.
4. Enregistrer.

Le fichier `index.html` doit rester à la racine du dépôt.
